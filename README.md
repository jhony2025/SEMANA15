## 📖 Descripción
Este proyecto consiste en una **aplicación de lista de tareas con interfaz gráfica (GUI)** desarrollada en **Python utilizando Tkinter**.  
Permite gestionar de manera sencilla las actividades diarias, con funciones para añadir, marcar como completadas y eliminar tareas.  

El objetivo principal de este trabajo es **consolidar los conocimientos de programación orientada a objetos y desarrollo de interfaces gráficas**, aplicando manejo de eventos y diseño de ventanas.

---

## 🎯 Funcionalidades
- **Añadir tarea:** ingresar texto en el campo y añadirlo con el botón o la tecla **Enter**.  
- **Marcar como completada:** seleccionar una tarea y marcarla con el botón correspondiente o mediante **doble clic**.  
- **Eliminar tarea:** eliminar la tarea seleccionada de la lista.  
- **Indicadores visuales:**  
  - Las tareas completadas se muestran con el prefijo `✔`.  
  - Colores personalizados para mejorar la usabilidad.  
  - Fuente legible y botones con íconos (➕ ✔ 🗑).  

---

## 🖼️ Interfaz
La ventana principal incluye:  
- Campo de texto para escribir la tarea.  
- Botones de acción: **Añadir**, **Marcar Completada**, **Eliminar**.  
- Lista visual de tareas agregadas.
